# HATUA - Step / Milestone / Take Action 🇰🇪

**HATUA** is a walking and fitness application designed for the East African market. The name means "Step", "Milestone", or "Take Action" in Kiswahili.

## Project Structure

- `DESIGN.md`: Comprehensive design document covering market analysis, features, avatars, pricing, and roadmap.
- `prototype/`: An interactive React-based prototype demonstrating the core user interface of the application.

## Getting Started with the Prototype

The prototype is built using React and Vite. To run it locally:

1.  Navigate to the prototype directory:
    ```bash
    cd prototype
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
4.  Open your browser to the URL provided (usually `http://localhost:5173`).

## Key Screens in the Prototype

- **Activity (Odometer)**: Live tracking with multiple modes (Outdoor, Indoor, Race) and activities (Walk, Jog, Bike, Race).
- **Explore (Map)**: Interactive route selection (Uhuru Park, CBD, Ngong Hills) with AI suggestions.
- **Goals (Challenges)**: Join community challenges and track progress.
- **Rank (Leaderboard)**: Competitive ranking with podium and localized avatars.
- **Store (Rewards)**: Redeem points for M-Pesa, Airtime, or planting trees.
- **Profile**: Personal stats and referral program.
